## Validation and significant outcomes

- **Stock GPU/Power gaps closed, not incorrectly marked absent:** PVT fragment48 is a one-property Boolean only; GPU 13 levels `900..220MHz`, CX/GX raw levels, indexed bus limits and DDR table published from actual compiled public reference. No vendor vote indexes directly ported as upstream ICC rates. Actual phone selected reference overlay still unknown.
- **VPU SMMU second cell resolved by upstream code:** `arm_smmu_of_xlate` interprets `0x400` as **SMR stream-match mask** for SID `0x2180` and `0x2187`. `arm_smmu_attach_dev` assigns all stream matches of one Linux consumer to **one** context bank, so two IOMMU entries do not implement vendor's separate bitstream/pixel domains. Missing Linux two-domain DMA ownership is a functional hold.
- **Fourth vendor VPU clock understood structurally:** `video_cc_mvs0_clk_src` is an ancestor behind source divider and branch with `CLK_SET_RATE_PARENT` in `videocc-sm8450.c`; no independent fourth child-clock gate necessarily needed. Vendor rate/parent frequency ratio suggests /3 **[INFERRED]**; actual divider and RPMh `mxc/mmcx` required-OPP corner assignments remain unavailable.
- **Stock 3-path ICC versus provisional Iris 2-path** and lack of LLCC dynamic votes remain concrete driver/DT mismatch. Do not copy Qualcomm Android vendor endpoint indices directly to upstream `qcom,sm8450.h` provider namespace or invent absent policy.
- **MBN/MDT segments:** VPU one-file `vpu20_4v.mbn` ELF32 has 20 phdrs; hash segment **index19 PT_NULL flagged HASH** inside MBN, size 4712B; 7MiB relocatable `qcom_mdt_get_size`. Split MDT same 7MiB size; **only** phdr1..9 and 18 request ten `bXX` load files, exact source sizes; metadata hash is packed into MDT. A730 ZAP MDT 3 phdrs, needs **`.b01`** 2236B; index2 PT_NULL hash 3896B packed in MDT; relocatable, load size 4KiB, stock shader carveout 8KiB. First audit mistakenly filtered TYPE_HASH to PT_LOAD, corrected as pinned `qcom_mdt_read_metadata` actually tests flags irrespective of `p_type`. Corrected CI now refuses empty hash results. **Structural host loader checks only**, PAS signed acceptance and HFI Gen2 untested.
