# Razr 2022 NUC

Native mainline Linux port for the Motorola Razr 2022 (`oneli`, Snapdragon 8+ Gen 1 / SM8475).

## Hardware research

The [hardware audit overview](docs/razr2022_linux_audit_readme_2026-10-11.md) summarises the findings and the evidence status. The [machine-readable hardware database](docs/razr2022_native_linux_hardware_database_2026-10-11.json) contains individual components, upstream driver mappings, device-tree records, board revisions and direct links to pinned Motorola and Linux source commits.

Research snapshot: **11 October 2026**. This is a hardware-source audit, **not** a verified native Linux boot or a finished Razr mainline device tree.
